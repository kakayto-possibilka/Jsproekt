# Портал «Конференции.РФ»

Информационная система для бронирования помещений для проведения Всероссийских конференций.

## Стек

- **Backend:** Node.js + Express
- **БД:** SQLite (`better-sqlite3`)
- **Шаблоны:** EJS
- **Стили:** Bootstrap 5.3 (локально)
- **Хэширование:** bcryptjs
- **Сессии:** express-session

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

Открыть `http://localhost:3000`.

## Что студент должен дописать

| Файл                           | Что дописать                                                                                                                                   |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **`db.js`**                    | Хэширование паролей в seed, методы `UserModel`, `RoomModel`, `RequestsModel`                                                                   |
| **`server.js`**                | `POST /register`, `POST /login`, `GET /dashboard`, `GET/POST /create`, `GET/POST /admin`, `GET /rooms`, `GET /request/:id`, `POST /review/:id` |
| **`views/auth.ejs`**           | Flash, ошибки валидации, сохранение значений                                                                                                   |
| **`views/rooms.ejs`**          | Счётчик, фильтрация, пустое состояние                                                                                                          |
| **`views/requests_list.ejs`**  | Заголовок, счётчик, бейдж статуса, ФИО/логин, «Подробнее», форма смены статуса                                                                 |
| **`views/create_request.ejs`** | Блок ошибок                                                                                                                                    |
| **`views/request_detail.ejs`** | Всё содержимое (карточка, отзыв, форма)                                                                                                        |
| **`public/css/style.css`**     | Анимации, адаптив                                                                                                                              |
| **`docs/schema.sql`**          | SQL-дамп структуры                                                                                                                             |
| **`docs/er_diagram.png`**      | ER-диаграмма                                                                                                                                   |
| **`README.md`**                | Пользователи, роли, структура, маршруты, безопасность                                                                                          |
